O que é <iframe>

	A tag <iframe> (inline frame) é usada em HTML para
inserir outra página web dentro da sua página.

	É como uma janela dentro da página, que carrega
outro conteúdo — pode ser um site, vídeo, mapa,
formulário, etc.

ex básico:

<iframe src="https://www.exemplo.com" width="600"
height="400"></iframe>

👍 Vantagens (Prós):
✅ Permite incorporar conteúdo externo, como vídeos
do YouTube, mapas do Google Maps, formulários, etc.

✅ Útil para documentação, pré-visualização de sites, ou ferramentas externas.

✅ Simples de usar — só precisa da URL no src.


👎 Desvantagens (Contras):
⚠️ Pode aumentar o tempo de carregamento da página
(principalmente se o conteúdo externo for pesado).

⚠️ Problemas de segurança, como ataques do tipo click
jacking.

⚠️ Muitos sites (como o Instagram ou Facebook)
bloqueiam uso de iframe por segurança — exibem erro
ou página em branco.

⚠️ Dificulta acessibilidade e SEO (os robôs de busca
não leem bem o conteúdo dentro de um <iframe>).

⚠️ Difícil de estilizar por completo — você não 
consegue alterar o CSS interno da página embutida 
(a menos que tenha controle sobre ela).

Navegação no iframe

	A ideia é usar o <iframe> como um “visor” dentro
da página, onde o conteúdo muda dinamicamente ao
clicar em links — sem abrir nova aba ou sair da
página.

	Isso funciona com o uso do atributo target nos
links, e o atributo name no iframe.
ex:

<!-- O iframe tem um nome -->
<iframe name="visor"></iframe>

<!-- Esses links abrem dentro do iframe -->
<a href="pagina1.html" target="visor">Página 1</a>
<a href="pagina2.html" target="visor">Página 2</a>

	Agora, ao clicar em qualquer link, o conteúdo 
será carregado dentro do iframe chamado "visor".

Aula 06

Inconvenientes do <iframe>

	Durante essa aula, o professor destaca os principais
contras do uso da tag <iframe>, que incluem:

- Segurança limitada

	1. O iframe é como se você convidasse alguém para
entrar em sua "casa", se você não conhece a "pessoa" e
suas intenções isso pode ser perigoso, então tome
muito cuidado. pois nada impede que o dono do site
que você colocou dentro do iframe altere o código
e adicione algo que seja malicioso e acabe prejudicando
os seus viewers.

	2. XSS – Cross-Site Scripting
🧠 O que é:
	XSS (Cross-Site Scripting) é um tipo de ataque onde
um código malicioso (geralmente JavaScript) é
injetado numa página web.

	O atacante tenta fazer com que outros usuários
executem scripts sem perceber, roubando dados ou
alterando o site.

	Se um site não filtrar bem os dados que os usuários
enviam (como formulários ou comentários), esse script
pode ser salvo e executado por outros usuários.

🎯 Riscos do XSS:
Roubo de cookies e sessões
Redirecionamento para sites falsos
Exibição de conteúdo falso ou malicioso

	3. Cross-Site (CSRF e embutidos com iframe)
O termo “Cross-Site” se refere a ações maliciosas
entre sites diferentes, e pode envolver:

	CSRF (Cross-Site Request Forgery): forçar o navegador 
da vítima a enviar requisições indesejadas para outro 
site em que ela já está logada.

	Uso abusivo de <iframe>: carregar um site dentro de 
outro para enganar o usuário (ex: clickjacking).

	Clickjacking
Definição: Técnica que “sequestra” um clique do
usuário, escondendo elementos maliciosos sob um
<iframe> transparente.

Proteção: Sites usam headers como X-Frame-Options:
DENY ou Content-Security-Policy: frame-ancestors
'none' para evitar que sejam embutidos em iframes
maliciosos.

	3. Same-Origin Policy & sandbox
Conteúdo de domínios diferentes é isolado por padrão
— você não pode manipular ou acessar diretamente o
DOM do conteúdo externo.

	Para maior segurança, o atributo sandbox pode ser
usado para restringir ainda mais o que pode acontecer
dentro do iframe:

<iframe src=".."
  sandbox="allow-scripts"
  sandbox="allow-same-origin">
</iframe>
	Isso impede ações como execução de scripts, envio
de formulários etc., se essas permissões não estiverem
explicitamente definidas.

- Problemas de desempenho

	Carregar páginas externas no <iframe> pode deixar
o site mais lento.

- Compatibilidade restrita

	Muitos sites bloqueiam a exibição em <iframe>
por políticas de segurança.

- Acessibilidade e SEO prejudicados

	Leitores de tela e motores de busca costumam
ignorar o conteúdo dentro do iframe.

- Dificuldade de estilização e controle

	Você não consegue alterar o CSS ou comportamento
interno do iframe (a menos que seja do mesmo domínio).

Tornando iframes mais seguros

	Usando o parâmetro sandbox com valor "sandbox"
dentro da tag iframe, bloqueamos a captura de dados

	Usando o parâmetro referrerpolicy com valor
"no-referrer" o navegador não envia nenhuma informação 
sobre a página de origem (de onde o usuário veio) 
para o site de destino.

✅ Benefícios de no-referrer
🛡️ Mais privacidade: o site de destino não sabe de 
onde o usuário veio.

🔒 Evita exposição de URLs sensíveis (como parâmetros 
de login, tokens etc.).

🔐 Útil quando você não quer passar dados da sua 
aplicação para terceiros.

⚠️ Possível impacto:
Sites de terceiros que dependem do referrer para 
rastreamento ou autenticação podem bloquear ou 
recusar o acesso.

Pode quebrar certas integrações se o site remoto 
espera um referrer válido.

{red}
	Então sempre que for usar um iframe digite a
seguinte sequencia de códigos para ter mais segurança:

<iframe ... sandbox="sandbox(ou adicione apenas os 
'allow' necessários)" referrerpolicy="no-referrer">
</iframe>
{red}

Valores sandbox:

sandbox				Forma mais restritiva e segura
allow-scripts		Permite rodar JavaScript
allow-forms			Permite envio de formulários
allow-same-origin	Permite acesso ao mesmo domínio
allow-popups		Permite abrir pop-ups
allow-modals		Permite alertas, prompts etc.

{red}
	Ao usar sandbox com algum dos valores allow...
todos os outros que não forem permitidos estarão
bloqueados!.
{red}

✅ O que é a tag <label> em um formulário?
	A tag <label> é usada para dar um nome ou descrição
a um campo de formulário, como caixas de texto,
seletores, botões etc.

	Ela associa um texto a um campo, tornando o 
formulário mais claro e mais acessível, principalmente para 
leitores de tela.

🧠 Benefícios:
🖱️ Clicar no rótulo ativa o campo correspondente 
(melhor usabilidade).

♿ Leitores de tela entendem melhor o formulário 
(acessibilidade).

🔤 Ajuda o usuário a saber exatamente o que preencher.

📌 Três formas de usar <label>:
1. Como foi ensinado no curso:
html
<p><label for="inome">Nome:</label> 
	<input type="text" name="nome" id="inome"></p>
<p><label for="isobrenome">Sobrenome:</label> 
   <input type="text" name="sobrenome" id="isobrenome"></p>
<p><input type="submit" value="Enviar"></p>

2. Usando for e id (mais comum)
html
<label for="email">E-mail:</label>
<input type="email" id="email">

3. Aninhando o input dentro do label
html
<label>
  E-mail:
  <input type="email" name="email">
</label>

	Essa forma também associa o texto ao campo, sem 
precisar usar for ou id.

Métodos GET e POST

✅ O que são method="get" e method="post" em formulários?
	O atributo method define como os dados do formulário 
serão enviados ao servidor quando o usuário clicar 
em "enviar".

GET:
	Anexa os dados na URL (?nome=joao)
quando usar?
	Quando os dados não são sensíveis e você só quer 
buscar informações.

POST:
	Envia os dados no corpo da requisição
quando usar?
	Quando os dados são privados ou vão alterar algo 
(cadastros, login, envio de mensagens etc.)

⚠️ Resumo prático:
Use GET quando:

Os dados não forem confidenciais
Você quiser compartilhar ou salvar o link
A ação não altera dados no servidor

Use POST quando:

Os dados forem sensíveis (senhas, mensagens, cadastro)
A ação mudar algo no banco de dados
Houver muitos dados (GET tem limite de tamanho na URL)

🔡 O que são minlength e maxlength na tag <input>
Os atributos servem para definir limites de caracteres 
que o usuário pode digitar em campos de formulário.

minlength	Define o mínimo de caracteres obrigatórios
maxlength	Define o máximo de caracteres permitidos

ex:
<label for="iusu"> Usuário: </label>
<input type="text" name="usu" id="iusu" required
	 minlength="5" maxlength="15">
	 
	o parâmetro size define o tamanho da barra de
dados para cada input. ex: size="10", a barra ficará
com tamanho para caber 10 caracteres por vez, caso 
tiver mais de 10 habilitará uma rolagem lateral.
	placeholder é um parâmetro que define o que
deve ser digitado na barra em que foi adicionado
por input. ex:

<input type="text" name="usu" id="iusu" required 
minlength="5" maxlength="15" placeholder="Digite 
seu usuário">

✅ O que é o atributo autocomplete no <input>
	O atributo serve para dizer ao navegador se ele 
deve sugerir preenchimentos automáticos (baseados em 
dados já salvos pelo usuário, como nome, e-mail, 
endereço, senha etc.).
Exemplo de valores:
name, email, username, current-password, new-password	

Valores específicos que ajudam o navegador a entender 
melhor o tipo de dado

Select, datalist e textarea

✅ Como funcionam as tags <option> e <optgroup> 
dentro de <select>
	A tag <select> é usada para criar listas suspensas 
(dropdowns) em formulários.
	Dentro dela, usamos <option> para listar as 
escolhas disponíveis, e <optgroup> para organizar 
essas opções em grupos.

🔽 Tag <option>
Define cada item da lista que o usuário pode escolher.
ex:
<select name="cidade">
  <option value="sp">São Paulo</option>
  <option value="rj">Rio de Janeiro</option>
</select>

- O que aparece para o usuário: "São Paulo", "Rio 
de Janeiro".
- O que é enviado no formulário: "sp" ou "rj" (valor 
do atributo value).

📁 Tag <optgroup>
Serve para dividir as opções em categorias, melhorando 
a organização e a legibilidade.
ex:
    <option value="css">CSS</option>
  </optgroup>

  <optgroup label="Design">
    <option value="figma">Figma</option>
    <option value="xd">Adobe XD</option>
  </optgroup>
</select>

- O usuário vê os grupos "Desenvolvimento" e "Design".
- Cada grupo tem suas próprias opções.
- O atributo label é obrigatório em <optgroup>.

{red}
	Você pode usar "selected" dentro de <option> 
para deixar uma opção marcada por padrão:
	Também pode usar disabled em <option> ou <optgroup> 
para desativar opções.
{red}

✅ O que é <datalist> e list no <input>
	A tag <datalist> permite criar uma lista de 
sugestões que aparece enquanto o usuário digita em 
um campo de entrada (<input>).

	Essas sugestões são apenas ajudas visuais — o 
usuário ainda pode digitar o que quiser.
ex:
<label for="cor">Escolha uma cor:</label>
<input type="text" id="cor" name="cor" list="cores">

<datalist id="cores">
  <option value="Vermelho">
  <option value="Verde">
  <option value="Azul">
  <option value="Amarelo">
</datalist>

📝 O que é a tag <textarea>
	A tag <textarea> é usada para criar um campo de 
texto com várias linhas em um formulário — ideal 
para mensagens, comentários, descrições ou qualquer 
texto longo que o usuário precise digitar.
ex:
<label for="mensagem">Mensagem:</label><br>
<textarea id="mensagem" name="mensagem" rows="5" cols="30"></textarea>

| Atributo      | O que faz                                              |
| ------------- | ------------------------------------------------------ |
| `rows`        | Define a **altura** do campo (em linhas de texto)      |
| `cols`        | Define a **largura** (em caracteres)                   |
| `placeholder` | Mostra um texto temporário até o usuário digitar       |
| `maxlength`   | Limita o número de caracteres                          |
| `required`    | Torna o preenchimento obrigatório                      |
| `readonly`    | O campo é visível, mas **não pode ser editado**        |
| `disabled`    | O campo é desativado e **nem é enviado no formulário** |

🎨 Estilização
	Por padrão, o <textarea> vem com borda e 
redimensionador, mas você pode estilizar com CSS:
textarea {
  resize: none; /* impede o redimensionamento */
  padding: 10px;
  border-radius: 5px;
  font-size: 16px;
}

📱 O que são Media Queries em CSS?

	Media Queries são regras do CSS que permitem 
aplicar estilos diferentes dependendo do tamanho da 
tela (largura, altura), tipo de dispositivo (celular, tablet, monitor), resolução, e até orientação (paisagem ou retrato).

	Elas são a base do design responsivo, que adapta 
o site para ficar bonito e funcional em qualquer tela.

🎯 Quando usar?

| Caso                                 | Media Query indicada                  |
| ------------------------------------ | ------------------------------------- |
| Ajustar layout para celular          | `max-width: 600px`                    |
| Exibir ou ocultar elementos          | `display: none` dentro de media query |
| Mudar tamanhos de fonte, espaçamento | Ideal para leitura em telas pequenas  |
| Mostrar imagens diferentes           | Combinado com HTML `<picture>` ou CSS |

📌 Dica prática:
Você pode colocar várias media queries no seu CSS, 
como por exemplo:

/* Estilo padrão (desktop) */

@media (max-width: 1024px) { /* tablet */ }
@media (max-width: 768px) {  /* celular em paisagem */ }
@media (max-width: 480px) {  /* celular em pé */ }

🔗 O que é o atributo media na tag <link>?
O atributo media na tag <link> é usado para aplicar 
um arquivo CSS somente em determinadas condições de 
tela, usando o mesmo conceito de media queries.

Ele permite carregar estilos diferentes para diferentes 
tamanhos de tela, sem precisar escrever todas as 
regras no mesmo arquivo.
ex:
<link rel="stylesheet" href="style.css" media="
(max-width: 600px)">

Isso significa:
“Use esse arquivo CSS apenas se a tela tiver até 
600px de largura.”

🧠 Quando usar o media no <link>?
Você usa o media quando quer:

Separar os estilos por arquivos (ex: desktop.css, 
mobile.css)

- Melhorar a performance, carregando só o necessário
- Organizar melhor o seu projeto

ex com dois arquivos:
<!-- Estilos padrão (desktop) -->
<link rel="stylesheet" href="style.css">

<!-- Estilos para dispositivos móveis -->
<link rel="stylesheet" href="mobile.css" media="
(max-width: 768px)">

✅ Vantagens:
| Benefício              | Por quê?                                  |
| ---------------------- | ----------------------------------------- |
| 📁 Organização modular | Separa os estilos por dispositivo         |
| ⚡ Performance          | Evita carregar estilos desnecessários     |
| 🔄 Mais controle       | Decide exatamente quando o CSS será usado |

🧪 Dica extra:
Você pode combinar com outros tipos de media:
<link rel="stylesheet" href="print.css" media="
print">

	Isso aplica estilos somente quando a página for 
impressa.

Múltiplas Media Features

{red}
	Media Query = Media Types + Media Features
{red}

✅ Os 4 principais Media Types do CSS

| Media Type | Significado                                           | Quando é usado?                                            |
| ---------- | ----------------------------------------------------- | ---------------------------------------------------------- |
| `all`      | Todos os dispositivos                                 | ✅ Padrão — usado quando **não há restrição**               |
| `screen`   | Dispositivos com tela (monitores, celulares, tablets) | ✅ Usado para a maioria dos sites responsivos               |
| `print`    | Impressão em papel                                    | 🖨️ Aplicado quando o usuário **imprime a página**         |
| `speech`   | Leitores de tela para acessibilidade                  | 🧑‍🦯 Usado em navegadores com suporte a voz (pouco comum) |

✅ As media features mais usadas no CSS
Aqui estão as mais comuns e úteis no dia a dia do 
design responsivo:

| Media Feature          | O que verifica                                        | Exemplo de uso                        |
| ---------------------- | ----------------------------------------------------- | ------------------------------------- |
| `width`                | A **largura exata** da tela ou viewport               | `@media (width: 1024px)`              |
| `min-width`            | **Mínima largura** da tela (ou maior)                 | `@media (min-width: 768px)`           |
| `max-width`            | **Máxima largura** da tela (ou menor)                 | `@media (max-width: 600px)`           |
| `height`               | Altura exata do viewport                              | `@media (height: 800px)`              |
| `min-height`           | Mínima altura da tela                                 | `@media (min-height: 500px)`          |
| `max-height`           | Máxima altura da tela                                 | `@media (max-height: 900px)`          |
| `orientation`          | Se a tela está em **paisagem** ou **retrato**         | `@media (orientation: portrait or landscape)`      |
| `aspect-ratio`         | Proporção da tela (largura/altura)                    | `@media (aspect-ratio: 16/9)`         |
| `resolution`           | Resolução da tela (usado para impressão ou retina)    | `@media (min-resolution: 300dpi)`     |
| `pointer`              | Tipo de ponteiro (fino, grosso ou nenhum)             | `@media (pointer: coarse)`            |
| `hover`                | Se o dispositivo **suporta hover** (ex: mouse)        | `@media (hover: none)`                |
| `prefers-color-scheme` | Detecta se o usuário prefere **modo claro ou escuro** | `@media (prefers-color-scheme: dark)` |

🎯 Dica de ouro:
As mais usadas para design responsivo tradicional são:

- min-width
- max-width
- orientation
- prefers-color-scheme

	Essas quatro já resolvem 90% dos casos de 
responsividade e adaptação ao usuário.

Exemplo de uso no HTML para projetos grandes

<link rel="stylesheet" href="estilos/style.css" media="all">
<link rel="stylesheet" href="estilos/retrato.css" media="screen and (orientation: portrait)">
<link rel="stylesheet" href="estilos/paisagem.css" media="screen and (orientation: landscape)">

Mobile First – HTML5 e CSS3

	Mobile First é uma abordagem de design e 
desenvolvimento onde o site ou aplicativo é planejado 
e construído primeiro para telas pequenas (celulares), 
e depois adaptado para telas maiores (tablets e 
desktops).

A ideia é começar simples, garantindo que funcione 
bem no celular, e depois adicionar melhorias conforme 
o espaço de tela aumenta.

🧠 Como funciona na prática
- Começa com o layout para mobile (menor largura 
de tela, geralmente até 480px ou 600px).

- Prioriza conteúdo essencial e velocidade de 
carregamento.

- Só depois adiciona elementos extras que funcionam 
melhor em telas grandes.

✅ Vantagens do Mobile First

| Benefício                        | Por que é importante?                                 |
| -------------------------------- | ----------------------------------------------------- |
| 📱 Melhor experiência no celular | Hoje a maioria dos acessos vem de dispositivos móveis |
| ⚡ Performance                    | Carrega rápido em conexões lentas                     |
| 🎯 Foco no essencial             | Evita excesso de elementos que poluem a tela pequena  |
| 🔄 Escalabilidade                | Fica mais fácil adaptar para telas maiores depois     |

		}

📜 Como Funciona o código JavaScript

function clickMenu() {
    if (itens.style.display == 'block') {
        itens.style.display = 'none'
    } else {
        itens.style.display = 'block'
    }
}

1️⃣ Definição da função

- function clickMenu() { ... }
- function → palavra-chave para criar uma função.
- clickMenu → nome da função, escolhido pelo desenvolvedor.

O conteúdo dentro das chaves {} será executado toda 
vez que a função for chamada.

2️⃣ Acesso ao elemento itens

- if (itens.style.display == 'block') { ... }
- O itens aqui se refere ao id="itens" do HTML:

<menu id="itens"> ... </menu>
Em navegadores, elementos com id podem ser acessados 
diretamente pelo nome como variável.

style.display → acessa a propriedade CSS display 
aplicada diretamente no elemento via JavaScript.

3️⃣ Estrutura condicional if / else
Se (if) o valor de display for "block" → significa 
que o menu está visível na tela, então:

itens.style.display = 'none'
→ Esconde o menu.

Senão (else) → significa que o menu está oculto, então:

itens.style.display = 'block'
→ Mostra o menu.

4️⃣ Ligação com o clique
No HTML, o ícone tem:

<span id="burguer" ... onclick="clickMenu()">menu</span>
O atributo onclick chama a função clickMenu() quando 
o usuário clica no ícone.

Esse clique aciona o teste (if) e alterna a visibilidade 
do menu.

🔄 Resumo do processo

- O usuário clica no ícone (<span>).
- O atributo onclick chama a função clickMenu().
- O JavaScript verifica se o menu (itens) está visível.
- Alterna entre display: none e display: block para 
esconder ou mostrar o menu.

Diferença entre o caractere igual(=).

| Símbolo | Função                   | Faz conversão de tipo? |
| ------- | ------------------------ | ---------------------- |
| `=`     | Atribui valor            | ❌ Não se aplica        |
| `==`    | Compara só o valor       | ✅ Sim                  |

function mudouTamanho() { ... }
Cria uma função chamada mudouTamanho.

O conteúdo dentro das chaves {} será executado toda 
vez que essa função for chamada (seja manualmente ou 
via evento resize).

if (window.innerWidth >= 768) { ... }
window.innerWidth → retorna a largura interna da 
janela do navegador em pixels, sem contar a barra 
de rolagem vertical.

O if verifica se essa largura é maior ou igual a 768px.

Esse número (768) foi escolhido como ponto de corte

itens.style.display = 'block';
Mostra o menu (itens) definindo display: block,

itens.style.display = 'none';
Esconde o menu (display: none), deixando apenas o 
ícone do hambúrguer visível.

Isso força o usuário de celular a usar o botão para 
abrir o menu.

🔄 Resumo do comportamento
- Checa o tamanho da tela.
- Mostra o menu se a largura for 768px ou mais.
- Esconde o menu se for menor que 768px.

Essa função é útil para garantir que o menu sempre 
volte para o estado certo quando o usuário muda o 
tamanho da tela, evitando que o menu continue escondido 
no desktop depois de ter sido fechado no mobile.

Outras media queries para login

Novas propriedades usadas nessa aula:

1. float

Função: Faz um elemento “flutuar” para a esquerda 
ou direita dentro do seu contêiner, permitindo que 
outros elementos fiquem ao lado dele.

Valores comuns:
left → flutua à esquerda.
right → flutua à direita.
none → padrão, sem flutuação.

2.transition

Função: Cria uma transição suave entre o estado inicial 
e o estado final de uma propriedade CSS.

Sintaxe geral:
transition: propriedade duração delay timing-function;

Exemplo:

button {
  background-color: blue;
  transition: background-color 0.3s ease;
}

button:hover {
  background-color: red;
}

	Aqui, a cor de fundo muda de azul para vermelho 
suavemente em 0.3 segundos.

3. transition-timing-function

Função: Define o ritmo da transição (como a velocidade 
muda ao longo do tempo).

Valores comuns:

linear → velocidade constante.
ease → começa devagar, acelera, depois desacelera (padrão).
ease-in → começa devagar e acelera.
ease-out → começa rápido e desacelera.
ease-in-out → começa e termina devagar.
cubic-bezier(x1, y1, x2, y2) → curva personalizada.

Exemplo:

div {
  transition: transform 0.5s ease-in-out;
}

div:hover {
  transform: scale(1.2);
}
