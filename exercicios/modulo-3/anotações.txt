Caption
		
	<caption> é uma tag usada para colocar um
título em uma tabela HTML. Ela aparece geralmente
acima da tabela e serve para descrever o que a
tabela mostra.

Escopo de Títulos em tabelas

	Por enquanto vamos usar os valores "col" e "row":
- col: Significa que o título da célula (<th>) vale
		para a coluna inteira.
- row: Significa que o título da célula (<th>) vale
		para a linha inteira.
		
Aula 06
		
Efeito Zebrado

O que é a pseudo-classe :nth-child()		
	A nth-child() é uma pseudo-classe do CSS usada
para selecionar elementos com base em sua posição
dentro do pai (ordem dos irmãos).

🔹 Selecionar o segundo parágrafo:
p:nth-child(2)

🔹 Selecionar todos os elementos em posições pares:
css
li:nth-child(even)

🔹 Selecionar todos os elementos em posições ímpares:
css
li:nth-child(odd)

🔹 Selecionar cada 3 elementos (3, 6, 9…):
css
div:nth-child(3n)

✅ Exemplo prático:
html
<ul>
  <li>One</li>     <!-- 1st child -->
  <li>Two</li>     <!-- 2nd child -->
  <li>Three</li>   <!-- 3rd child -->
</ul>

css
li:nth-child(2) {
  color: red;
}

Isso pinta "Two" de vermelho ✅

Aula 07								11/07/25

Cabeçalho Fixo

	Muito útil quando se tem muitas colunas. Fazendo
isso você está fixando o cabeçalho da tabela(<thead>
ou <th>) no topo da tela enquanto o usuário rola o
conteúdo da tabela.
html
<div class="tabela-wrapper">
  <table>
    <thead>
      <tr>		*É necessário os fechamentos*
        <th>Nome</th>
css
.tabela-wrapper {
  max-height: 300px;
  overflow-y: auto;
  position: relative;
}

thead th {
  position: sticky;
  top: 0;
  background-color: white; /* importante para cobrir o conteúdo ao rolar */
  z-index: 1;
}

Aula 08									15/07/25

Mesclagem de Células

	Usando *colspan="valor"* inline podemos expandir
uma célula para ocupar mais colulas.
HTML
	<table>
		<tr>
			<td>A</td>
			<td colspan="2">B</td>
		</tr>
	
	Nesse caso a linha B ocupa o espaço de 2 colunas.
	
	Usando *rowspan="valor"* inline podemos expandir
uma célula para ocupar mais linhas.
HTML
	<table>
		<tr>
			<td>D</td>
			<td>E</td>
			<td rowspan="3">F</td>
		</tr>

Aula 11								16/07/25

Escopo de Tabela

	Escopos de tabela servem para organizar e dar
significado aos dados, especialmente para leitores
de tela e acessibilidade. Eles são definidos com o
atributo scope nas células de cabeçalho (<th>), e
ajudam a indicar a que parte da tabela aquele
cabeçalho se refere.

col:	A célula <th> é título de uma coluna
row:	A célula <th> é título de uma linha
colgroup:	O <th> se refere a um grupo de colunas
rowgroup:	O <th> se refere a um grupo de linhas

Exemplo: ex023/table004.html

Aula 13								16/07/25

Agrupando Colunas com colgroup

	 O que é a tag <colgroup>
A tag <colgroup> é usada dentro de uma <table> para
agrupar uma ou mais colunas, e geralmente serve para
aplicar estilos diretamente a essas colunas — como
cor de fundo, largura, borda etc.

Ela não exibe conteúdo, mas ajuda a controlar a
aparência de colunas inteiras de forma mais organizada.

ex:
HTML
<table>
  <colgroup>
    <col class="c-name">
    <col class="c-age">
    <col class="c-country">
  </colgroup>
  <tr>
    <th>Name</th>
    <th>Age</th>
    <th>Country</th>
  </tr>
  <tr>
    <td>Joel</td>
    <td>25</td>
    <td>Brazil</td>
  </tr>
</table>

CSS
col.c-name {
	background-color: lightgreen;
}

	Dessa forma toda a coluna name ficará com um
fundo light green.

	Caso queria que várias colunas fiquem com o mesmo
estilo sem ter que repetir a mesma classe, use o
parâmetro span="valor". Lembrando que essa forma só
funciona quando as colunas estão juntas.
ex:
HTML
  <colgroup>
    <col>
    <col class="destaque" span="3">
  </colgroup>
  
  <tr>
    <th>1</th>
    <th>2</th>
    <th>3</th>
    <th>4</th>
    <th>5</th>
    <th>6</th>
  </tr>
  
	Nesse caso da coluna 2 à 4 ficaria com a classe
destaque e poderiam ter estilos diferentes das demais.

Aula 14								17/07/25

Tabelas Responsivas

	Quando a tabela ultrapassa o tamanho da tela,
acontece o problema que é a rolagem lateral, para
resolver basta envelopar toda a tabela dentro de uma
<div> e adicionar em CSS um overflow-x= auto; na div,
e a página ficará normal, apenas a tabela terá rolagem
lateral.
