Hierarquia de Tabelas (simples)

table = tabela
	table row = linha de tabela
		table header = cabeçalho de tabela
		table data = dado de tabela

for um dado usar "td".
{red}
		
Juntando os dados da Tabela

	usando "border-collapse" que tem o valor padrão
separate, mude para collapse e os dados ficarão juntos.

	Se os dados não forem colocados na hierarquia
correta eles aparecerão antes ou depois e fora da
tabela.

Aula 05								10/07/25

Caption
		
	<caption> é uma tag usada para colocar um
título em uma tabela HTML. Ela aparece geralmente
acima da tabela e serve para descrever o que a
tabela mostra.

Escopo de Títulos em tabelas

	Por enquanto vamos usar os valores "col" e "row":
- col: Significa que o título da célula (<th>) vale
		para a coluna inteira.
- row: Significa que o título da célula (<th>) vale
		para a linha inteira.
		
Aula 06
		
Efeito Zebrado

O que é a pseudo-classe :nth-child()		
	A nth-child() é uma pseudo-classe do CSS usada
para selecionar elementos com base em sua posição
dentro do pai (ordem dos irmãos).

🔹 Selecionar o segundo parágrafo:
p:nth-child(2)

🔹 Selecionar todos os elementos em posições pares:
css
li:nth-child(even)

🔹 Selecionar todos os elementos em posições ímpares:
css
li:nth-child(odd)

🔹 Selecionar cada 3 elementos (3, 6, 9…):
css
div:nth-child(3n)

✅ Exemplo prático:
html
<ul>
  <li>One</li>     <!-- 1st child -->
  <li>Two</li>     <!-- 2nd child -->
  <li>Three</li>   <!-- 3rd child -->
</ul>

css
li:nth-child(2) {
  color: red;
}

Isso pinta "Two" de vermelho ✅

Aula 07								11/07/25

Cabeçalho Fixo

	Muito útil quando se tem muitas colunas. Fazendo
isso você está fixando o cabeçalho da tabela(<thead>
ou <th>) no topo da tela enquanto o usuário rola o
conteúdo da tabela.
html
<div class="tabela-wrapper">
  <table>
    <thead>
      <tr>		*É necessário os fechamentos*
        <th>Nome</th>
css
.tabela-wrapper {
  max-height: 300px;
  overflow-y: auto;
  position: relative;
}

thead th {
  position: sticky;
  top: 0;
  background-color: white; /* importante para cobrir o conteúdo ao rolar */
  z-index: 1;
}
