Introdução ao Flexbox

📌 O que é Flexbox?

	O Flexbox (Flexible Box Layout) é um modelo de layout do CSS que facilita a organização de elementos em linhas ou colunas, permitindo que eles se ajustem automaticamente ao espaço disponível.

	Ele é ótimo para criar layouts responsivos, sem precisar usar float, inline-block ou tabelas.
	
	Ativando o Flexbox
	
	Se esticar vertical mente, os filhos também vão esticar porque a propriedade stretch por padrão vem ativada.
	


Para usar, basta aplicar:

.container { /* PAI */
  display: flex;
}

.items {	/* FILHOS */
	flex:auto
}

Agora, o .container se torna um flex container(PAI), e todos os elementos dentro dele se tornam flex items [itens flexíveis(FILHOS)].

Direções e eixos

flex-direction (conteiner pai)


1. Eixo principal (main axis)

-	Direção em que os itens são organizados.

-	Controlado por flex-direction:

row → linha (padrão, da esquerda para a direita). Mas pode ser da direita para a esquerda caso o idioma se leia o contrário.

row-reverse → linha invertida.

column → coluna (de cima para baixo).

column-reverse → coluna invertida.


2. Eixo cruzado (cross axis)

-	Perpendicular ao eixo principal.

-	Se o flex-direction for row, o eixo cruzado é vertical; se for column, o cruzado é horizontal.

Empacotamento e fluxo

flex-wrap → controla se os itens quebram de linha:

-	nowrap: (padrão, todos na mesma linha) Não é para quebrar os items dentro do container, mas isso depende do conteúdo dentro dos items.

-	wrap: (quebram se necessário) Quando diminuir mais que o tamanho dos items, a caixa vai quebrar na direção do cross-axis.

-	wrap-reverse: (quebram invertido) Diminuindo além do limite, o item que quebrar vai para o lado contrário do cross-axis.

	
	Shorthand: flex-flow= flex-direction+flex-wrap.
	
	
{red}
	Melhor Forma para praticar é ativando o DevTools e mexendo nos valores atravez dele, porque as mudanças são instantaneas.

Alinhamentos nos eixos

Configuração para o Container PAI

justify-content vai fazer o alinhamento na direção do main-axis. 
valores:
	
-	flex-start: o primeiro item será alinhado com relação ao main-start e o espaço em branco ficará no final do main-end.
	
-	flex-end: o último item será alinhado com o main-end e o espaço em branco ficará no main-start.
	 
-	center: os items ficarão alinhados no centro do container e os espaços em brancos serão iguais nos main-end e main-start.

-	space-between: o primeiro item ficará colado no main-start, o último ficará no main-end e todos os outros ficarão no meio com um espaço igual entre eles.
	
-	space-evenly: os items ficarão alinhados no centro com espaçamentos iguais entre os main-start, main-end e items.
	
-	space-around: divide o espaço do container para a quantidade de items em tamanhos iguais e alinha os items no centro desse tamanho dividido.


align-items vai fazer o alinhamento na direção do cross-axis.
valores:

-	stretch: padrão, ao aumentar o tamanho do cross-axis, ele estica também os items.

-	flex-start: alinha os items com o cross-start e cria um espaço até o cross-end.

-	flex-end: alinha os items com o cross-end e cria um espaço até o cross-start.

-	center: centraliza os items com relação ao cross-axis.

Anatomia dos itens flexbox

Essas 2 Propriedades Servem para os FILHOS.

Propriedade "ORDER"

	Todo item por padrão tem "order: 0;", a ordem começa com os número negativos depois vai pro 0 e ai vai pros positivos.
ex:
-3,-1,0,4,5,10

	A melhor forma para configurar o order, é com css inline.
ex:

<div class="conteiner">
	<div class="item" style="order: 5;">A</div>
	<div class="item" style="order: 3;">B</div>
	<div class="item" style="order: 1;">C</div>
	<div class="item" style="order: 7;">D</div>
	<div class="item" style="order: 6;">E</div>
	<div class="item" style="order: 4;">F</div>
	<div class="item" style="order: 2;">G</div>
</div>


Propriedade "Align-Self"

	Essa propriedade é alinhada em relação ao cross-axis e permite sobrescrever o align-items apenas para aquele item.
valores:

-	auto: padrão, herda o valor determinado no Conteiner PAI.

-	stretch: ao aumentar o tamanho do cross-axis, ele estica também os items.

-	flex-start: alinha os items com o cross-start e cria um espaço até o cross-end.

-	flex-end: alinha os items com o cross-end e cria um espaço até o cross-start.

-	center: centraliza os items com relação ao cross-axis.

ex:

<div class="conteiner">
	<div class="item" style="align-self: auto;">A</div>
	<div class="item" style="align-self: flex-end;">B</div>
	<div class="item" style="align-self: center;">C</div>
	<div class="item" style="align-self: stretch;">D</div>
	<div class="item" style="align-self: flex-start;">E</div>
</div>

Tamanho base dos itens


flex-basis - Propriedade de Item
	
	Altera o tamanho do main-axis do item antes de crescer/encolher.

valores:

-	auto: padrão, tamanho é definido através do conteúdo, quanto mais será maior.

-	Pode ser px, %, etc: caso escolha um valor, esse será o valor máximo que terá cada item, porém caso precise ele irá diminuir até onde der, depois disso caso esteja setado como nowrap, ele irá quebrar o conteúdo.

Pode crescer ou diminuir

	flex-shrink é o quanto pode encolher - Propriedade de Item
valor padrão é 1. 
	1 significa sim(pode encolher) e 0 significa não(não pode encolher).

-	2: vai ser o duas vezes menor que o item 1. Caso tenha 3 items, um com 0 e os outros dois com 2, o primeiro terá o tamanho do flex-basis e os outros 2 terão encolherão no limite do conteiner e terão tamanhos iguais.

	flex-grow é o quanto pode crescer - Propriedade de Item
valor padrão é 0. 
	1 significa sim(pode crescer) e 0 significa não(não pode crescer).
	
-	2: vai ser o dobro do item 1. Caso tenha 3 items, um com 0 e os outros dois com 2, o primeiro terá o tamanho do flex-basis e os outros 2 terão crescerão no limite do conteiner e terão tamanhos iguais.
	
	flex-grow permite items de valores diferentes!.	
	
{red}
	Com flex-shrink e flex-grow com valor 1, os items ficam totalmente flexiveis ao tamanho do conteiner PAI.
{red}


🔹 Como funciona o cálculo para flex-grow

	O navegador distribui o espaço disponível no container (aquele que sobra depois de aplicar larguras fixas, margens, paddings etc.).

	Esse espaço é dividido em partes proporcionais de acordo com os valores de flex-grow.

👉 O que importa não é o número em si, mas a proporção entre eles.

📊 Exemplo prático

css
.item1 { flex-grow: 0; } /* não cresce */
.item2 { flex-grow: 2; } /* cresce */
.item3 { flex-grow: 6; } /* cresce ainda mais */


	Imagine que o container tenha 900px de largura disponíveis depois de aplicar margens e paddings.

Somatório dos flex-grow:
0 + 2 + 6 = 8 partes.

Distribuição:

Item1 (0) → não recebe espaço extra, só ocupa o tamanho mínimo/base.

Item2 (2) → recebe 2/8 = 25% do espaço disponível.

Item3 (6) → recebe 6/8 = 75% do espaço disponível.

Se o espaço disponível for 800px, por exemplo:

Item2 → 200px

Item3 → 600px

Item1 → apenas o tamanho inicial (sem crescer).


🔹 Como funciona o cálculo para flex-shrink

Soma dos flex-shrink = 0 + 2 + 6 = 8 partes.

	Só os itens com valor maior que 0 participam da divisão.

	O espaço que precisa ser removido (150px) será dividido em 2/8 e 6/8.

📊 Distribuição

css
.item1 { flex-shrink: 0; } /* não encolhe */
.item2 { flex-shrink: 2; }
.item3 { flex-shrink: 6; }


Item1 (0) → não encolhe, continua com 150px.

Item2 (2/8) → perde 37,5px → fica com 112,5px.

Item3 (6/8) → perde 112,5px → fica com 37,5px.


✅ Diferenças importantes

	flex-grow → distribui crescimento (quando sobra espaço).

	flex-shrink → distribui redução (quando falta espaço).

	Um valor maior sempre significa que o item cresce ou encolhe mais em relação aos outros.

	Se o item tiver flex-shrink: 0, ele não diminui nunca, mesmo que os outros precisem encolher mais.

Simplificando com Flex
	
	Shorthand flex - Propriedade para Items
	
	ordem: flex-grow > flex-shrink > flex-basis
	
ex:
flex: 0 1 100px;

| Atalho          | Expansão completa | O que faz                                                               
| --------------- | ----------------- | ------------------------------------------------------------------------------------------------
| `flex: initial` | `0 1 auto`        | Padrão: não cresce, pode encolher, base no tamanho do conteúdo.         
| `flex: auto`    | `1 1 auto`        | Cresce e encolhe conforme espaço, base no conteúdo. É a forma que o conteúdo fica mais flexível.                     |
| `flex: none`    | `0 0 auto`        | Fixo, sem crescer/encolher. É a forma menos flexível.                                            
| `flex: 1`       | `1 1 0%`          | Atalho para definir apenas o flex-grow.
