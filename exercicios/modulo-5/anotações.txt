Introdução ao CSS Flexbox

📌 O que é Flexbox?

	O Flexbox (Flexible Box Layout) é um modelo de layout do CSS que facilita a organização de elementos em linhas ou colunas, permitindo que eles se ajustem automaticamente ao espaço disponível.

	Ele é ótimo para criar layouts responsivos, sem precisar usar float, inline-block ou tabelas.
	
	Ativando o Flexbox
	
	Se esticar vertical mente, os filhos também vão esticar porque a propriedade stretch por padrão vem ativada.
	


Para usar, basta aplicar:

.container { /* PAI */
  display: flex;
}

.items {	/* FILHOS */
	flex:auto
}

Agora, o .container se torna um flex container(PAI), e todos os elementos dentro dele se tornam flex items [itens flexíveis(FILHOS)].

Direções e eixos

flex-direction (conteiner pai)


1. Eixo principal (main axis)

-	Direção em que os itens são organizados.

-	Controlado por flex-direction:

row → linha (padrão, da esquerda para a direita). Mas pode ser da direita para a esquerda caso o idioma se leia o contrário.

row-reverse → linha invertida.

column → coluna (de cima para baixo).

column-reverse → coluna invertida.


2. Eixo cruzado (cross axis)

-	Perpendicular ao eixo principal.

-	Se o flex-direction for row, o eixo cruzado é vertical; se for column, o cruzado é horizontal.

Empacotamento e fluxo

flex-wrap → controla se os itens quebram de linha:

-	nowrap: (padrão, todos na mesma linha) Não é para quebrar os items dentro do container, mas isso depende do conteúdo dentro dos items.

-	wrap: (quebram se necessário) Quando diminuir mais que o tamanho dos items, a caixa vai quebrar na direção do cross-axis.

-	wrap-reverse: (quebram invertido) Diminuindo além do limite, o item que quebrar vai para o lado contrário do cross-axis.

	
	Shorthand: flex-flow= flex-direction+flex-wrap.

Alinhamentos nos eixos

Configuração para o Container PAI

justify-content vai fazer o alinhamento na direção do main-axis. 
valores:
	
-	flex-start: o primeiro item será alinhado com relação ao main-start e o espaço em branco ficará no final do main-end.
	
-	flex-end: o último item será alinhado com o main-end e o espaço em branco ficará no main-start.
	 
-	center: os items ficarão alinhados no centro do container e os espaços em brancos serão iguais nos main-end e main-start.

-	space-between: o primeiro item ficará colado no main-start, o último ficará no main-end e todos os outros ficarão no meio com um espaço igual entre eles.
	
-	space-evenly: os items ficarão alinhados no centro com espaçamentos iguais entre os main-start, main-end e items.
	
-	space-around: divide o espaço do container para a quantidade de items em tamanhos iguais e alinha os items no centro desse tamanho dividido.


align-items vai fazer o alinhamento na direção do cross-axis.
valores:

-	stretch: padrão, ao aumentar o tamanho do cross-axis, ele estica também os items.

-	flex-start: alinha os items com o cross-start e cria um espaço até o cross-end.

-	flex-end: alinha os items com o cross-end e cria um espaço até o cross-start.

-	center: centraliza os items com relação ao cross-axis.

Pode crescer ou diminuir

	flex-shrink é o quanto pode encolher - Propriedade de Item
valor padrão é 1. 
	1 significa sim(pode encolher) e 0 significa não(não pode encolher).

-	2: vai ser o duas vezes menor que o item 1. Caso tenha 3 items, um com 0 e os outros dois com 2, o primeiro terá o tamanho do flex-basis e os outros 2 terão encolherão no limite do conteiner e terão tamanhos iguais.

	flex-grow é o quanto pode crescer - Propriedade de Item
valor padrão é 0. 
	1 significa sim(pode crescer) e 0 significa não(não pode crescer).
	
-	2: vai ser o dobro do item 1. Caso tenha 3 items, um com 0 e os outros dois com 2, o primeiro terá o tamanho do flex-basis e os outros 2 terão crescerão no limite do conteiner e terão tamanhos iguais.
	
	flex-grow permite items de valores diferentes!.	
	
{red}
	Com flex-shrink e flex-grow com valor 1, os items ficam totalmente flexiveis ao tamanho do conteiner PAI.
{red}


🔹 Como funciona o cálculo para flex-grow

	O navegador distribui o espaço disponível no container (aquele que sobra depois de aplicar larguras fixas, margens, paddings etc.).

	Esse espaço é dividido em partes proporcionais de acordo com os valores de flex-grow.

👉 O que importa não é o número em si, mas a proporção entre eles.

📊 Exemplo prático

css
.item1 { flex-grow: 0; } /* não cresce */
.item2 { flex-grow: 2; } /* cresce */
.item3 { flex-grow: 6; } /* cresce ainda mais */


	Imagine que o container tenha 900px de largura disponíveis depois de aplicar margens e paddings.

Somatório dos flex-grow:
0 + 2 + 6 = 8 partes.

Distribuição:

Item1 (0) → não recebe espaço extra, só ocupa o tamanho mínimo/base.

Item2 (2) → recebe 2/8 = 25% do espaço disponível.

Item3 (6) → recebe 6/8 = 75% do espaço disponível.

Se o espaço disponível for 800px, por exemplo:

Item2 → 200px

Item3 → 600px

Item1 → apenas o tamanho inicial (sem crescer).


🔹 Como funciona o cálculo para flex-shrink

Soma dos flex-shrink = 0 + 2 + 6 = 8 partes.

	Só os itens com valor maior que 0 participam da divisão.

	O espaço que precisa ser removido (150px) será dividido em 2/8 e 6/8.

📊 Distribuição

css
.item1 { flex-shrink: 0; } /* não encolhe */
.item2 { flex-shrink: 2; }
.item3 { flex-shrink: 6; }


Item1 (0) → não encolhe, continua com 150px.

Item2 (2/8) → perde 37,5px → fica com 112,5px.

Item3 (6/8) → perde 112,5px → fica com 37,5px.


✅ Diferenças importantes

	flex-grow → distribui crescimento (quando sobra espaço).

	flex-shrink → distribui redução (quando falta espaço).

	Um valor maior sempre significa que o item cresce ou encolhe mais em relação aos outros.

	Se o item tiver flex-shrink: 0, ele não diminui nunca, mesmo que os outros precisem encolher mais.

| Atalho          | Expansão completa | O que faz                                                               
| --------------- | ----------------- | ------------------------------------------------------------------------------------------------
| `flex: initial` | `0 1 auto`        | Padrão: não cresce, pode encolher, base no tamanho do conteúdo.         
| `flex: auto`    | `1 1 auto`        | Cresce e encolhe conforme espaço, base no conteúdo. É a forma que o conteúdo fica mais flexível.                     |

| `flex: 1`       | `1 1 0%`          | Atalho para definir apenas o flex-grow.

O que é Grid Layout

	"CSS Grid Layout é um sistema para criação de layouts baseado em uma grade bidimensional e otimizado para design de interfaces de usuário. Nesse modelo de grade, os elementos-filhos do container que defina a grade podem ser posicionados livremente em espaços criados na estrutura, quer ela tinha sido definida com suas dimensões flexíveis ou fixas."
	
-	É um modelo de layout bidimensional (funciona em linhas e colunas).

-	Você define um container grid e dentro dele os elementos se organizam automaticamente como células de uma tabela flexível.

✅ Resumo

-	Flexbox é ótimo para 1D (linha ou coluna).

-	Grid é perfeito para 2D (linha e coluna juntas).

Anatomia do Grid

Imagem 1

Grid Container

-	É o elemento pai que recebe display: grid;.
-	Ele cria uma grade (linhas e colunas) que organiza os elementos filhos.

Grid Item

-	São os elementos filhos diretos do container.
-	Cada um ocupa uma ou mais células dentro dessa grade.

Imagem 2

Grid Track

-	É o espaço entre duas linhas de grade (grid lines).
-	Pode ser tanto na horizontal (row track) quanto na vertical (column track).

Row Track

-	É uma trilha horizontal da grade → representa a altura de uma trilha (row).

Column Track

-	É uma trilha vertical da grade → representa a largura de uma trilha (column).

Imagem 3,4

Grid Lines 

-	São as linhas de referência que formam a grade (grid).
-	Elas aparecem tanto na direção horizontal (row grid lines) quanto na direção vertical (column grid lines).
-	Cada grid line recebe um número automático, começando em 1.

Na imagem:

-	As grid lines verticais e horizontais estão numeradas de 1 a 7.
-	Isso permite que você posicione e dimensione grid items com base nesses números.

Imagem 5

Cada grid line pode ser referenciada de duas formas:

-	Números positivos → começam no 1 da esquerda para a direita (ou de cima para baixo).
-	Números negativos → começam no -1 da direita para a esquerda (ou de baixo para cima).
-	Isso permite que você defina posições de grid items de forma mais flexível, sem precisar contar todas as grid lines manualmente.

Na horizontal:
A grid line 2 (positiva, da esquerda para direita).
A grid line -2 (negativa, da direita para esquerda).

Na vertical:
A grid line 2 (positiva, da esquerda para direita).
A grid line 3 (positiva, da esquerda para direita).

Imagem 6

Grid Area

-	É formada pela interseção de grid rows e grid columns.
-	Ou seja: é o espaço dentro do grid delimitado por 4 grid lines (topo, base, esquerda e direita).
-	Um grid area pode conter uma única célula ou várias células combinadas.

Na imagem:

-	O grid area mostrado vai da grid line 2 a 5 (vertical) e da grid line 2 a 5 (horizontal).
-	Isso cria um bloco que ocupa 3 column tracks e 3 row tracks.

Imagem 7,8,9

Gap

-	É o espaço entre os grid items dentro de um grid container.
-	Ele não afeta as bordas externas do container, apenas o espaço interno entre os itens.
-	Esse espaço pode ser definido separadamente na direção das colunas (column-gap) e das linhas (row-gap).

Resumindo

-	gap = cria um espaço uniforme entre os grid items.
-	row-gap = controla apenas o espaço entre row tracks.
-	column-gap = controla apenas o espaço entre column tracks.
-	Facilita muito a organização visual, sem precisar usar margens (margin) nos elementos.

Propriedades de container para Grids (parte 4)


-	Como funciona a função repeat no grid layout?

	A função repeat() no CSS Grid Layout serve para não precisar escrever valores repetidos no grid-template-columns ou grid-template-rows.

repeat(quantidade, tamanho)

quantidade → número de vezes que o valor será repetido.
tamanho → pode ser qualquer medida válida (px, %, fr, minmax(), etc).

grid-template: 100px 100px auto / auto auto auto;

será substituído por:

grid-template: repeat(2, 100px 100px) auto / repeat(3, auto);

Usando auto-fill ou auto-fit:

css:
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

📌 Diferença:

auto-fill → preenche o grid com o máximo de colunas possíveis, mesmo que algumas fiquem “vazias”.
auto-fit → faz os itens se esticarem para ocupar o espaço disponível se sobrar.


-	Unidade fracional

📌 Como funciona

-	O fr divide o espaço restante (aquele que sobra depois de descontar margens, gap, tamanhos fixos em px, %, etc).

-	Cada valor em fr representa uma parte proporcional dessa sobra.

🔹 Exemplos práticos

1. Colunas iguais
css
grid-template-columns: 1fr 1fr 1fr;

➡️ O espaço disponível é dividido em 3 partes iguais.


2. Colunas proporcionais
grid-template-columns: 1fr 2fr 1fr;


➡️ O espaço é dividido em 4 partes:

1ª coluna → 1 parte
2ª coluna → 2 partes
3ª coluna → 1 parte


3. Combinando px e fr
grid-template-columns: 200px 1fr 2fr;


➡️ Aqui:

1ª coluna → 200px fixos.
Espaço restante é dividido em 3 partes → 2ª coluna recebe 1 parte, 3ª recebe 2 partes.

✅ Resumindo

fr = fração do espaço disponível.
Mais simples e flexível que trabalhar só com %.
Facilita criar layouts proporcionais e responsivos.

grid-auto-flow

	Controla como os grid items são posicionados automaticamente dentro do Grid Layout.
- row (padrão)
	Os itens são inseridos linha por linha (row track por row track).
	Preenche primeiro na horizontal, depois “quebra” para a próxima linha.
- column
	Os itens são inseridos coluna por coluna (column track por column track).
	Preenche primeiro na vertical, depois “quebra” para a próxima coluna.
- row dense ou column dense
	Funciona como column, mas também tenta compactar os espaços vazios. Tentam otimizar o espaço, preenchendo buracos.

Transformando SVG em XML e editando via código


📌 1. O que é um arquivo SVG

	SVG (Scalable Vector Graphics) → é um formato de imagem vetorial baseado em XML.

	Isso significa que, em vez de pixels (como PNG ou JPG), o SVG é escrito como código com tags e atributos (bem parecido com HTML).

	Por ser texto, você pode abrir um .svg em um editor e editar direto no código.


📌 2. Como transformar .svg em .xml

	Na prática, não precisa converter.

	Um .svg já é um XML válido.

	O que você pode fazer é abrir o arquivo .svg no Visual Studio Code, ou até salvar como .xml → vai funcionar do mesmo jeito porque a estrutura é XML.


📌 3. Como editar SVG com HTML e CSS	

	Quando você coloca o SVG inline no HTML, pode estilizar as partes usando CSS. Criando uma tag <style> dentro do XML e apartir dai editando e depois basta voltar para ".svg" e voltará a ser uma imagem porém agora com as modificações.
	

📌 4. Modificações mais usadas em SVG (via CSS/HTML)
🎨 Cores

fill → cor de preenchimento da forma (circle, path, rect, etc).

stroke → cor da borda da forma.

stroke-width → espessura da borda.

Exemplo:

path {
  fill: blue;
  stroke: black;
  stroke-width: 2px;
}


🔄 Transformações

transform: rotate(45deg) → rotaciona.

transform: scale(1.5) → aumenta.

transform: translate(10px, 20px) → move.


✨ Efeitos

opacity: 0.5 → deixa transparente.

filter: drop-shadow(2px 2px 5px gray) → adiciona sombra.

filter: blur(3px) → desfoca.


🎬 Animações

Você pode animar qualquer propriedade do SVG:

circle {
  fill: red;
  transition: fill 0.5s;
}
circle:hover {
  fill: green;
}


📌 5. Diferença entre usar <img src="icone.svg"> e <svg>...</svg>

	Se você usar <img>, o SVG é tratado como uma imagem comum → você não pode editar com CSS interno.

	Se você colocar o SVG inline no HTML (copiando o código <svg>...</svg>), aí sim pode estilizar partes individuais com CSS.


✅ Resumindo

	O SVG já é XML → abrir e editar é como mexer em HTML.

	Colocando inline no HTML, você pode alterar:
	
	-	Cores: fill, stroke, stroke-width.
	-	Transformações: scale, rotate, translate.
	-	Efeitos: opacity, filter (sombra, blur).
	-	Animações: transition, @keyframes.

	O jeito mais poderoso de trabalhar com SVG é colar o código no HTML, não só usar <img>.

Topo Social


📌 1. O que é aspect-ratio?

	Define a proporção entre largura e altura de um elemento.

Sintaxe
aspect-ratio: largura / altura;

🔹 Exemplos
.box1 {
  width: 300px;
  aspect-ratio: 16 / 9; /* largura 16, altura 9 */
  background: lightblue;
}

.box2 {
  height: 200px;
  aspect-ratio: 1 / 1; /* quadrado perfeito */
  background: lightgreen;
}


➡️ O navegador calcula automaticamente a outra dimensão para manter a proporção.

📌 2. O que é object-fit

	Controla como o conteúdo de mídia (<img>, <video>, <iframe>, etc.) se ajusta dentro de seu container.

📌 Valores mais usados
object-fit: fill;       /* padrão → estica para preencher, pode distorcer */
object-fit: contain;    /* ajusta sem cortar, cabe inteiro dentro do container */
object-fit: cover;      /* preenche o container, corta se necessário */
object-fit: none;       /* mantém tamanho original, pode "vazar" do container */
object-fit: scale-down; /* usa o menor entre none e contain */

🔹 Exemplos
img.cover {
  width: 300px;
  height: 200px;
  object-fit: cover;   /* a imagem cobre toda a caixa, cortando excesso */
}

img.contain {
  width: 300px;
  height: 200px;
  object-fit: contain; /* a imagem inteira aparece, mas pode sobrar espaço */
}

✅ Diferença entre os dois

aspect-ratio → define a proporção da caixa (container do elemento).

object-fit → define como a mídia dentro da caixa se ajusta ao espaço disponível.
