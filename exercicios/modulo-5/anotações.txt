Introdução ao Flexbox

📌 O que é Flexbox?

	O Flexbox (Flexible Box Layout) é um modelo de layout do CSS que facilita a organização de elementos em linhas ou colunas, permitindo que eles se ajustem automaticamente ao espaço disponível.

	Ele é ótimo para criar layouts responsivos, sem precisar usar float, inline-block ou tabelas.
	
	Ativando o Flexbox
	
	Se esticar vertical mente, os filhos também vão esticar porque a propriedade stretch por padrão vem ativada.
	


Para usar, basta aplicar:

.container { /* PAI */
  display: flex;
}

.items {	/* FILHOS */
	flex:auto
}

Agora, o .container se torna um flex container(PAI), e todos os elementos dentro dele se tornam flex items [itens flexíveis(FILHOS)].

Direções e eixos

flex-direction (conteiner pai)


1. Eixo principal (main axis)

-	Direção em que os itens são organizados.

-	Controlado por flex-direction:

row → linha (padrão, da esquerda para a direita). Mas pode ser da direita para a esquerda caso o idioma se leia o contrário.

row-reverse → linha invertida.

column → coluna (de cima para baixo).

column-reverse → coluna invertida.


2. Eixo cruzado (cross axis)

-	Perpendicular ao eixo principal.

-	Se o flex-direction for row, o eixo cruzado é vertical; se for column, o cruzado é horizontal.

Empacotamento e fluxo

flex-wrap → controla se os itens quebram de linha:

-	nowrap: (padrão, todos na mesma linha) Não é para quebrar os items dentro do container, mas isso depende do conteúdo dentro dos items.

-	wrap: (quebram se necessário) Quando diminuir mais que o tamanho dos items, a caixa vai quebrar na direção do cross-axis.

-	wrap-reverse: (quebram invertido) Diminuindo além do limite, o item que quebrar vai para o lado contrário do cross-axis.

	
	Shorthand: flex-flow= flex-direction+flex-wrap.

Aula 04

Alinhamentos nos eixos

Configuração para o Container PAI

justify-content vai fazer o alinhamento na direção do main-axis. 
valores:
	
-	flex-start o primeiro item será alinhado com relação ao main-start e o espaço em branco ficará no final do main-end.
	
-	flex-end: o último item será alinhado com o main-end e o espaço em branco ficará no main-start.
	 
-	center: os items ficarão alinhados no centro do container e os espaços em brancos serão iguais nos main-end e main-start.

-	space-between: o primeiro item ficará colado no main-start, o último ficará no main-end e todos os outros ficarão no meio com um espaço igual entre eles.
	
-	space-evenly: os items ficarão alinhados no centro com espaçamentos iguais entre os main-start, main-end e items.
	
-	space-around: divide o espaço do container para a quantidade de items em tamanhos iguais e alinha os items no centro desse tamanho dividido.


align-items vai fazer o alinhamento na direção do cross-axis.
valores:

-	stretch: padrão, ao aumentar o tamanho do cross-axis, ele estica também os items.

-	flex-start: alinha os items com o cross-start e cria um espaço até o cross-end.

-	flex-end: alinha os items com o cross-end e cria um espaço até o cross-start.

-	center: centraliza os items com relação ao cross-axis.
